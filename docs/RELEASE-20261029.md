## 安全版本

Next.js / eslint-config-next 15.5.28，React / React DOM 19.0.9，sharp 0.35.5，NextAuth 4.24.15，Zod 4.6.7，MapLibre 6.16.0，PostCSS 8.5.32，Prisma / Client 6.19.0。

参考：[Next.js 官方公告](https://nextjs.org/blog/nextjs-security-update-october-14-2026)、[NextAuth 公告](https://github.com/advisories/GHSA-7rqj-j65f-68wh)、[MapLibre 公告](https://github.com/advisories/GHSA-jrc7-96c5-q579)、[Zod 公告](https://github.com/advisories/GHSA-mrhx-c7xc-m3w5)。地图弹窗改为 textContent 和 setDOMContent，不将港口名称拼入 HTML。PostCSS 的同主版本覆盖也应用到 Next.js 的传递依赖；npm ls 未报告版本冲突。

官方 npm 公告服务对最终锁文件仍有 18 条公告范围匹配，涉及 7 个传递依赖，不是 18 个独立可利用漏洞：

| 包 | 引入位置及本项目风险边界 |
| --- | --- |
| brace-expansion | ESLint/文件匹配工具；没有把 HTTP 参数作为 glob 表达式的已发现路径 |
| baseline-browser-mapping、browserslist | CSS/浏览器兼容性构建工具；当前只处理项目控制的配置 |
| deepmerge-ts、effect | @prisma/config 6.19.0 的精确依赖，属于 Prisma 配置/命令链；应用 API 不接收或执行用户提供的 Prisma 配置 |
| js-yaml | ESLint 配置链；没有业务 YAML 上传解析入口 |
| postcss-selector-parser | Tailwind 构建链；不在 API 中编译用户提交的 CSS |

这些告警没有被视为消失；保留 Prisma 6.19.0 兼容性，不用跨大版本强制修复来降低扫描数字。构建只使用受审查源码，不把不可信 YAML/CSS/glob/Prisma 配置送入这些工具。后续跟进上游兼容补丁。
